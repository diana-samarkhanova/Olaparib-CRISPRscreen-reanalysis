# Analysis inputs

Place real inputs in study directories matching `metadata/studies.tsv` and `metadata/comparisons.tsv`.
These files are not bundled in this starter. Guide-level count tables obtained from authors can be used directly with `mageck test`
after verifying their sample labels and format; a `mageck count` step is not required for that route.
Record source filenames and any transformations. Preserve original tables alongside derived inputs.
This directory is ignored by Git by default; curate the eventual public data distribution explicitly.
